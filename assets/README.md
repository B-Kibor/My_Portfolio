# Assets Folder Structure

## Images to Add:

### Logo
- **Location:** `public/assets/images/`
- **File:** `logo.png`
- **Description:** Your portfolio logo (50x50px recommended)

### Hero Section
- **Location:** `public/assets/images/banner/`
- **File:** `hero.jpg`
- **Description:** Your profile/hero image (420x380px recommended)

### Project Images
- **Location:** `public/assets/images/work/`
- **Files needed:**
  - `lawyershub.png` - LawyersHub project screenshot
  - `africalaw.png` - Africalawtech project screenshot
  - `pigdice.png` - Pig Dice project screenshot
  - `insta.png` - Insta Clown project screenshot
  - `github.png` - Github Search project screenshot
  - `news.png` - News Highlight project screenshot

## Instructions:
1. Add your logo to: `public/assets/images/logo.png`
2. Add your hero image to: `public/assets/images/banner/hero.jpg`
3. Add project screenshots to: `public/assets/images/work/`

All images will be automatically loaded by the React components.
